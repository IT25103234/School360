➕ Add New Book

📋 Quick Guidelines

  • ISBN must contain exactly 13 numeric digits (no symbols or text).
  • Author and Category fields accept text values only (no numbers).
  • Set copies to 0 and status Unavailable for out-of-stock books.
  • Use Edition History to track version updates.
  • Only books marked Unavailable can be permanently removed.

📋 Registration Notes

  • Suspended members cannot borrow or reserve books.
